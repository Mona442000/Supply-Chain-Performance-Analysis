Supply Chain Performance Analysis

Project Overview

This project focuses on analyzing supply chain performance for a beauty and personal care products business using Microsoft Power BI.

The dashboard provides insights into sales, inventory, production, transportation, and shipping performance to support better business decisions.

Project Objectives

* Monitor key supply chain performance indicators.
* Analyze product sales and revenue.
* Evaluate inventory and product availability.
* Compare transportation modes and shipping performance.
* Identify operational trends and improvement opportunities.

Dashboard Pages

1. Overview

Provides a high-level summary of supply chain performance through key performance indicators and interactive visuals.

2. Performance Analysis

Explores product performance, transportation distribution, revenue by product type, production volumes, and shipping routes.

3. Insights & Recommendations

Highlights key findings and provides recommendations to improve supply chain operations.

Tools Used

* Microsoft Power BI
* Power Query
* DAX

Key Performance Indicators

* Total Revenue
* Total Products Sold
* Total Stock
* Average Shipping Cost
* Average Lead Time

Key Insights

The analysis explores differences in revenue contribution, transportation mode distribution, shipping times, inventory levels, and product availability across product categories.
